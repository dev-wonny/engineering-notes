# 이 사이트에 대하여

## 목적

Engineering Notes는 백엔드와 커머스 시스템을 설계하고 운영하며 반복해서 마주치는 문제를 정리하는 개인 기술 위키입니다.

문서의 목표는 특정 시스템을 소개하는 것이 아니라 다음 질문에 답하는 것입니다.

- 어떤 문제가 있었는가?
- 어떤 제약이 의사결정을 어렵게 했는가?
- 어떤 대안을 비교했는가?
- 무엇을 선택했고, 어떤 비용을 감수했는가?
- 다른 환경에서는 선택이 어떻게 달라질 수 있는가?

## 주요 독자

- Java와 Spring 기반 백엔드를 설계하는 개발자
- PostgreSQL에서 기간 데이터와 이력을 다루는 개발자
- 상품, 가격, 주문, 재고 모델을 설계하는 개발자
- AWS에서 웹 애플리케이션을 배포하고 운영하는 개발자

## 문서의 성격

문서는 지속적으로 수정됩니다. 새로운 사실을 확인하거나 더 단순한 재현 방법을 찾으면 기존 결론도 바뀔 수 있습니다. 버전 의존적인 내용은 적용 버전과 공식 문서를 함께 확인해야 합니다.
