Ad Tracking / Data Collection
  • Java / Spring 기반 광고 Tracking·FDS 시스템과 운영 백오피스 개발
  • JavaScript SDK 및 외부 API를 이용해 YouTube·Instagram·Facebook 광고 데이터를 자동 수집하고 캠페인 상태 갱신
  • 반복적인 데이터 수집·상태 확인 업무를 자동화해 운영 대응 부담과 리스크 감소
Traffic & Log Analysis
  • 약 12대 광고 클릭 서버의 요청 패턴과 로그 분석
  • 불필요 요청을 추적·필터링해 요청량 약 20% 감소 및 불필요한 S3 로그 적재 감소
  • S3 / Athena 기반 로그 분석을 통해 트래픽과 운영 이슈 확인
Operation Automation & Infra Optimization

  • 외부 플랫폼 수집 데이터의 중복을 방지하는 로직을 적용하고 데이터 수집 정확도 90% 이상 유지
