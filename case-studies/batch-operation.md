# 배치 운영 구조

## 상태

공개 전환 후보로 선별한 주제입니다. Spring Batch, 애플리케이션 스케줄러, Quartz, 워크플로 오케스트레이터의 책임 경계를 독립 예제로 검증한 뒤 탐색 메뉴에 연결할 예정입니다.

## 다룰 질문

- 실행 시각과 업무 처리를 같은 컴포넌트가 책임해야 하는가?
- 다중 인스턴스에서 중복 실행을 어떻게 막는가?
- 재시작, 재시도, 멱등성을 어디에서 보장하는가?
- Job 실행 상태와 업무 처리 상태를 어떻게 연결하는가?

## 공개 작성 기준

- 실제 Job 이름, 실행 주기, 운영 규모는 사용하지 않습니다.
- 도구 비교는 기능 목록보다 장애·복구 시나리오를 기준으로 합니다.
- 최소 재현 Job과 실행 상태 검증 방법을 포함합니다.
