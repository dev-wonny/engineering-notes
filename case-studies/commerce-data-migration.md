# 커머스 데이터 마이그레이션

## 상태

공개 전환 후보로 선별한 주제입니다. 실제 시스템의 스키마, 데이터, 일정, 이관 도구를 제거한 재현 사례를 추가한 뒤 탐색 메뉴에 연결할 예정입니다.

## 다룰 질문

- 테이블 복사가 아니라 업무 의미 전환으로 범위를 정의하는 방법
- 키·코드·날짜·금액을 매핑하는 방법
- 건수, 컬럼 값, 관계, 업무 규칙을 단계별로 검증하는 방법
- 반복 리허설과 전환·복구 기준을 만드는 방법

## 공개 작성 기준

- 모든 테이블과 값은 임의 예제로 새로 만듭니다.
- 실제 데이터 건수와 일정은 사용하지 않습니다.
- 성공 사례보다 검증 쿼리와 실패 판정 기준을 중심으로 작성합니다.
